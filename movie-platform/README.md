# Movie Platform — Flutter

Movie discovery starter using TMDB metadata, search, posters, and an in-memory watchlist. It does not scrape streaming sites. Use only licensed, public-domain, or user-owned media for playback.

Setup: install Flutter, run flutter pub get, create a TMDB API Read Access Token, then run flutter run --dart-define=TMDB_TOKEN=YOUR_TOKEN. Never commit real API keys. Add Firebase Authentication and Firestore to enable synced accounts and watchlists.
