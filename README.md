# Malkify — Developer Portfolio

A collection of practical projects built with web technologies, Flutter, Firebase, Python, and public APIs.

## Projects

| Project | Stack | Description |
|---|---|---|
| [Weather App](./weather-app) | HTML, CSS, JavaScript | Search weather by city using OpenWeatherMap (API key required). |
| [Movie Platform](./movie-platform) | Flutter, Dart, Firebase, TMDB | Browse movie metadata and manage a personal watchlist. Streaming is limited to licensed, public-domain, or owner-provided media. |
| [AI Chatbot](./ai-chatbot) | Python, Flask, Gemini API | A simple web chatbot powered by Gemini. |
| [Task Manager](./task-manager) | Flutter, Dart, Firebase | Create, complete, and manage personal tasks. |

## Getting started

Each project has its own README with setup instructions. Never commit API keys, Firebase service-account files, or other secrets. Use local environment/config files and keep them out of Git.

## Status

These are starter implementations intended for learning and extension. Configure your own API keys and Firebase project before using integrations.
